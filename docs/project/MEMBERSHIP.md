# 會員管理與收款規劃

2026-09-06 更新：後臺改為獨立管理登入（免手機驗證），加入登入／登出／修改紀錄；
新會員手機維持必驗證，每個號碼臺灣日期每天最多發送 5 次。新增社群帳號綁定，
後臺修改密碼使用 Email 一次性連結；第一位管理員可免初次驗證在本機登入。
初始化工具與平台前置條件見 [帳號設定](ACCOUNT_SETUP.md)。

## 已實作：管理基礎

`/members` 提供會員登入、Email 搜尋、分頁名單、資格調整與操作紀錄。
帳號資料仍在 `EQUITY_AUTH_DB`，預設 `var/private/accounts.sqlite3`；行情更新不會替換這個檔案。

會員資格與管理角色分開：

| 資格 | 到期規則 | 收費意義 |
| --- | --- | --- |
| free | 無 | 免費資格 |
| monthly | 必填未來到期時間，UTC 秒數保存；到期當下視為免費 | 管理員授予限期資格，**不代表已收款** |
| complimentary | 無到期日，可由管理員撤回 | 永久招待進階資格，**不算營收** |

一般會員不能調整資格。管理員只能調整一般會員，不能修改自己或其他管理員；
擁有者可以授予或移除管理員角色，網頁不能移除擁有者。
更新須填原因，檢查版本以避免覆蓋他人修改，操作識別碼避免重試重複寫入。
稽核資料與變更在同一交易提交。

`EQUITY_MEMBERSHIP_ENFORCEMENT=1` 啟用 Web 持股 AI、持股圖片、技術圖圖片與 LINE 分析的共用資格檢查。
預設 `0`，避免尚未完成驗證服務與資格配置就中斷既有服務。LINE 須綁定網頁會員；
已有舊綁定的會員應在帳號頁重新產生一次綁定指令，以建立資格對照。手動持股與刪除指令保留。
內部 Bot market API 保留既有服務憑證驗證，不以公開前端會員權限替代。
這不是正式收款已開通的版本。

## 主機初始化

從專案根目錄，以專案 Python 執行：

```powershell
.\.venv\Scripts\python.exe -m equity.membership_admin migrate
.\.venv\Scripts\python.exe -m equity.membership_admin owner --email '你的現有已驗證帳號'
```

macOS/Linux 將執行器改為 `./.venv/bin/python`，模組參數相同。
遷移會先用 SQLite backup API 保存並驗證帳號備份，再執行交易式升級；不修改行情。
`owner` 只接受已有、啟用且已驗證的帳號，只能初始化一次。沒有預設管理員密碼，
不會把第一個公開註冊者自動升成擁有者。應先在隔離副本驗證，再升級正式帳號資料庫。
新建帳號可使用 `create-owner` 互動命令，不需要 SMTP；帳號已存在時不會覆寫密碼。
初始帳號限定本機來源，完成 Email 連結改密碼後才可透過外部網址登入。

## 註冊、密碼與必要手機驗證

使用者要求真實手機號碼驗證，LINE 綁定不等於手機驗證。
`/account` 已提供註冊（密碼與重複確認）、Email 驗證、登入、忘記密碼、修改密碼及手機驗證。
後端也要求確認密碼一致。修改密碼需目前密碼；修改或重設會增加 credential version，
使舊 access token 和 session token 立即失效。Email 驗證碼最多嘗試 5 次，重寄至少間隔
60 秒，每個 Email／用途每小時最多 5 次。SMTP 未設定不再假回報成功或印出驗證碼。

已串接 Twilio Verify adapter，新增 `account_phone`、`phone_challenge` 與限流紀錄。
號碼只接受台灣手機，正規化後以私有金鑰 HMAC 識別並以 Fernet 加密；完整號碼不回傳後臺。
每帳號或號碼發送間隔 60 秒、每小時最多 5 次，全站每日上限由 `PHONE_SMS_DAILY_LIMIT` 設定。
OTP 10 分鐘內有效，最多嘗試 5 次；服務端確認成功才寫入驗證紀錄。沒有免費假碼或驗證繞過。
新註冊者必須完成 Email 及手機驗證才可使用會員資料 API；既有本機遷移帳號保留原登入方式，
未被自動標示成手機已驗證。公開註冊不會授予管理角色。

設定 `PHONE_VERIFICATION_MODE=trial`、`TWILIO_ACCOUNT_SID`、`TWILIO_AUTH_TOKEN`、`TWILIO_VERIFY_SERVICE_SID` 及 SMTP；
未設定時註冊入口明確停用，API 拒絕建立新帳號。這些設定只代表具備設定值，還需要
實際寄信、台灣簡訊送達與正確驗證測試才能稱為正式可用。此輪全部使用合成帳號與模擬服務，
沒有傳送真實簡訊或 Email，沒有把任何現有會員改成招待或管理員。

電話驗證資料隨帳號刪除；刪除持股不代表刪除帳號或手機。手機發送防濫用紀錄在下一次
發送操作清除超過 24 小時資料、過期 challenge 同樣清除；不宣稱精準定時清除。

可評估 Twilio Verify：成功驗證費加上簡訊渠道費，不是永久免費。
正式啟用前仍需要服務帳號、實測台灣送達與費用預算確認。
[Twilio Verify 費率](https://www.twilio.com/en-us/verify/pricing)
[API 與試用限制](https://www.twilio.com/docs/verify/api/verification)

## 新台幣付款與商家結算

使用者目前為無統編個人，尚無金流帳號。建議先申請商家收款審核，
在資格確認前規劃「單次付款購買一個月、到期手動續費」，不要宣稱已可自動扣款。

- 綠界：個人信用卡一次付清可申請；定期定額列為特約賣家服務，需審核。
- LINE Pay：基本付款與預先授權不同，台灣預先授權需要另外申請。
- 標準撥款為銀行帳戶。目前未確認上述服務對此經營資格提供直接 USDT／USDC 結算。
- 會員訂單只在金流伺服器簽章/查詢確認成功、金額幣別商家一致後開通。
  前端成功跳轉不能作為收款證據。須處理重送、取消、退款、拒付與訂閱到期。
- 若營收入帳後自行換幣，與會員收款分開記帳；不得把購幣交易偽裝成會員訂閱付款，
  不得將會員引導到未揭露的購幣/KYC 流程。退款與續訂條件須清楚。
- 本專案沒有交易所換幣、自動下單或鏈上轉帳實作，也未持有相關權限。
