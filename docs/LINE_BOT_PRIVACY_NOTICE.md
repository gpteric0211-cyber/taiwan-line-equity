# LINE Bot 對話記憶隱私告知

版本：2026-08-28

本 LINE 股票分析服務為了承接使用者的後續提問，會在 LINE 回覆成功後保存必要的對話脈絡，
包含使用者傳送的文字、實際回覆文字、最近討論的股票、資料日期、問題焦點，以及使用者主動
表示的持有狀態或投資週期。圖片原檔不保存；圖片中可辨識的有限文字摘要可能隨對話保存，
但一律視為推估內容。

LINE User ID、group ID、room ID、message ID 與 webhook event ID 不以原文落庫，而是以本服務
專用金鑰轉成不可逆索引。對話內容、最近狀態與摘要使用認證加密保存在營運者本機，並與市場
行情資料庫分離。本地模型只取得有長度限制的必要上下文；記憶只協助理解前文，不能覆蓋本輪
最新市場資料或系統的正式股票判斷。

逐字問答最長保存 24 小時；加密 session、最後一次實際回覆、滾動摘要與個股摘要最長保存
30 天。到期資料會失效並由清理流程刪除，不作永久保存。不同 LINE 使用者、私人對話、群組及
聊天室範圍分開保存；無法確認個別使用者的群組事件不保存對話記憶。

使用者可隨時傳送「隱私告知」查看本摘要，傳送「清除記憶」刪除目前聊天範圍，或傳送
「刪除我的資料」刪除同一使用者的全部對話記憶。取消追蹤時也會執行刪除；LINE 撤回訊息會
從可用記憶排除，引用該訊息的摘要會失效。資料存取、更正、停止使用或刪除相關問題，可直接
透過本 LINE 官方帳號提出。

本服務目前以營運者本機程式與本地模型處理上述資料；若日後新增雲端模型、外部處理者、跨境
傳輸或變更保存目的與期間，應先更新本告知版本並重新向使用者說明。
